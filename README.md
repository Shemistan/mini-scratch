# Мини-Scratch

Упрощённый Scratch для простых 2D-игр из блоков. Работает локально: без
сервера, сборки и интернета.

## Запуск

Откройте `index.html` в браузере двойным щелчком. Если браузер ограничивает
файлы с `file://`, запустите локальный сервер:

```bash
python3 -m http.server 5051 --directory mini-scratch
# затем откройте http://localhost:5051
```

При первом запуске загружается пример «Поймай яблоко»: зелёный флажок запускает
игру, стрелки двигают корзину.

## Примеры

Кнопка «Примеры» открывает галерею готовых проектов для занятий. Они
выстроены по нарастанию сложности:

| Пример | Управление | Что показывает |
|---|---|---|
| Первые шаги 🐱 | клик по коту, пробел | события, движение, «всегда», отталкивание от края |
| Поймай яблоко 🍎 | стрелки | опрос клавиш, касание спрайтов, переменная-счёт |
| Динозавр 🦖 | пробел — прыжок | гравитация через переменную-скорость, зеркальный спрайт, случайный вид препятствия |
| Пинг-понг ⚽ | мышь | следование за мышью, направление, отражение угла |

Выбранный пример заменяет текущий проект, так что свою работу сначала сохраните
в файл. Новый пример добавляется функцией в `examples.js` и записью в `EXAMPLES`;
тест `каждый пример запускается…` проверит его автоматически.

## Что умеет

- **Редактор блоков.** Перетаскивание, стыковка, поля для чисел и текста, корзина, масштаб.
- **Сцена 480×360** с координатами как в Scratch: центр в (0, 0), y растёт вверх,
  направление 90 — вправо.
- **Несколько спрайтов.** У каждого свои скрипты, имя и вид (эмодзи). Спрайты
  можно перетаскивать по сцене и отражать зеркально — кнопкой «⇆ Зеркально»
  в панели спрайта или блоками из «Внешности».
- **Параллельные скрипты.** Каждый скрипт — отдельный поток; «ждать», «повторить»
  и «всегда» уступают ход, 30 тактов в секунду.
- **Переменные** — общие для всех спрайтов, значения видны на сцене.
- **Сохранение** — автоматически в браузере (`localStorage`) и вручную в файл
  `.json` через кнопки «Сохранить» и «Открыть…».

## Блоки

| Категория | Блоки |
|---|---|
| Движение | идти N шагов, повернуть ↻/↺, перейти в x/y, в случайное место, повернуться в направлении, изменить/установить x и y, оттолкнуться от края; x, y, направление |
| Внешность | сказать (на время), сменить вид, размер, показаться/спрятаться, отразить зеркально, зеркальное отражение вкл/выкл, отражён?, сменить фон |
| События | когда нажат флажок, когда клавиша нажата, когда спрайт нажат, когда я получу, передать |
| Управление | ждать, повторить, всегда, если / если-иначе, ждать до, повторять пока не, стоп |
| Сенсоры | касается края / мыши / спрайта, клавиша нажата, мышь нажата, x/y мыши, таймер |
| Операторы | + − × ÷ остаток, случайное, сравнения, и / или / не, соединить, округлить |
| Переменные | создать, задать, изменить, значение |

Чего нет по сравнению со Scratch: клонов, звуков, рисования костюмов, пера,
списков и собственных блоков.

## Устройство

| Файл | Что внутри |
|---|---|
| `index.html`, `style.css` | страница: редактор слева, сцена и спрайты справа |
| `blocks.js` | описание всех блоков в одной таблице `SPEC`, из неё строятся блоки и палитра |
| `runtime.js` | исполнитель: интерпретирует JSON-скрипты генераторами, не зависит от браузера |
| `app.js` | связывает Blockly, сцену, клавиатуру, мышь и хранение |
| `examples.js` | готовые примеры для галереи и мини-язык для их записи |
| `tests/runtime.test.js` | тесты исполнителя: `node mini-scratch/tests/runtime.test.js` |
| `vendor/blockly/` | Blockly 11.2.2 (Apache-2.0), локальная копия из npm |

Новый блок добавляется в два места: запись в `SPEC` (`blocks.js`) и ветка
`case` в `exec` или `evaluate` (`runtime.js`).

Для отладки из консоли браузера доступен `miniScratch`:
`miniScratch.runtime.vars`, `miniScratch.project`.
